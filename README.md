# 水循環シンポジウム 2026 in 留寿都 静的サイト

2026年9月26日・27日に開催予定のシンポジウム公式サイト第一版です。ビルドツールや外部ライブラリを使わず、HTML・CSS・JavaScriptだけで構成しています。

## デザインの基準

デザインは引き継ぎ資料の `DESIGN_SYSTEM.md` と `2026_水循環シンポジウム_in_留寿都_企画書.pptx` を正とします。独自のブランドカラーや書体は追加せず、次の指定を維持してください。

- 背景：`#6ED2F5` から `#2896E1` の対角グラデーション
- 基本文字・濃色パネル：`#18384E`
- 主アクセント：`#0E6FA8`
- 副アクセント：`#1B9FC6`
- 淡色カード：`#EFF7FC` / `#E6F3FA`
- 限定ハイライト：`#F2B138`
- フォント：Meiryo

## 起動方法

ビルド不要の静的サイトです。ローカルではリポジトリルートで任意の静的サーバーを起動してください。

```bash
python -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開きます。直接 `index.html` を開いても表示できます。

## 後から更新する場所

`index.html` 内で `data-update` を検索すると、登壇者・会場地図・参加登録の更新対象をすぐに見つけられます。各箇所の直前に差し替え内容のコメントも記載しています。

- `data-update="speakers"`：登壇者カード
- `data-update="venue-map"`：会場地図
- `data-update="registration"`：申込ボタン

日付・時刻・登壇者・関係機関を変更する際は、企画書の `CONTENT_SPEC.md` にある横断確認リストと照合してください。

## ロゴ

`img/logo.png` は黒背景除去済みの透過 PNG を使用しています。暫定処理版のため、輪郭ににじみが残る可能性があります。正規の透過 PNG または SVG が支給されたら差し替えてください。
